개인정보처리방침

1. 개인정보 수집 여부

해외여행 환전 계산기(exchange-calc-kr.netlify.app)는 별도의 개인정보를 수집하지 않습니다. 모든 계산은 사용자의 브라우저 내에서만 처리되며, 입력한 금액 등의 정보는 서버로 전송되지 않습니다.

2. 쿠키 및 로컬스토리지

본 사이트는 사용자 편의를 위해 브라우저의 로컬스토리지를 사용합니다.

  • 저장 항목: 다크모드/라이트모드 설정값, 여행 규정 커스텀 데이터
  • 저장 목적: 다음 방문 시 설정 유지
  • 저장 위치: 사용자 브라우저 내부 (서버 전송 없음)

3. 외부 API 사용

본 사이트는 실시간 환율 정보 제공을 위해 외부 환율 API를 사용합니다. 이 과정에서 사용자의 IP 주소가 해당 API 서버에 전달될 수 있으며, 이는 환율 데이터 수신을 위한 기술적 과정입니다. 별도의 개인정보는 수집되지 않습니다.

4. 광고 서비스

본 사이트는 Google AdSense 광고를 사용합니다. Google은 광고 게재를 위해 쿠키를 사용할 수 있으며, 이에 대한 자세한 내용은 Google 개인정보처리방침을 참고하세요.

5. 방침 변경

개인정보처리방침이 변경될 경우 본 페이지를 통해 공지합니다.

최종 수정일: 2025년 1월 1일
