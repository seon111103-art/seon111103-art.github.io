업로드비서 개인정보처리방침

시행일: 2026년 11월 18일

업로드비서(이하 "도구")는 운영자 본인이 직접 만든 영상을 운영자 본인의 YouTube 채널과 Instagram 계정에 올리기 위해 만든 개인용 업로드 도구입니다. 일반 이용자에게 제공되는 서비스가 아니며, 운영자 본인만 사용합니다.

1. 사용하는 정보와 권한

  • YouTube: Google OAuth를 통해 운영자 본인 채널에 동영상을 업로드하는 권한(youtube.upload)과 채널 이름 확인을 위한 읽기 권한(youtube.readonly)만 사용합니다.
  • Instagram: Instagram API를 통해 운영자 본인 계정에 릴스를 게시하는 권한만 사용합니다.
  • Telegram: 운영자 본인이 보낸 영상과 캡션만 받습니다. 다른 사용자가 보낸 메시지는 처리하지 않고 무시합니다.

2. 정보의 이용 목적

위 권한은 운영자가 직접 요청한 영상을 지정한 계정에 업로드하는 목적으로만 사용합니다. 다른 사람의 계정이나 데이터에는 접근하지 않습니다.

3. 저장과 보관

  • 로그인 정보(액세스 토큰)는 운영자 본인의 컴퓨터에만 저장되며, 외부 서버로 보내지 않습니다.
  • 업로드할 영상은 업로드가 끝난 뒤 최대 3일 안에 컴퓨터에서 자동으로 삭제됩니다.
  • Google 사용자 데이터를 판매하거나 제3자와 공유하지 않으며, 광고 목적으로 사용하지 않습니다.

4. 권한 철회

Google 계정의 보안 > 타사 앱 및 서비스에서 언제든지 업로드비서의 접근 권한을 해제할 수 있습니다. 해제하면 도구는 더 이상 업로드할 수 없습니다.

5. Google API 서비스 사용자 데이터 정책 준수

업로드비서가 Google API에서 받은 정보를 사용하고 전송하는 방식은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.
